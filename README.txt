Bimi catalog export

Open catalog.html in a browser to browse and search all 948 products offline.
products.json contains all captured product fields, descriptions (text and original HTML), category/brand/country/vendor selections, listing data, source URLs, image URLs, and image-to-file mappings.
images/ contains every collected main and gallery image. Multiple products may share the same image file.
image_manifest.json maps original image URLs to local files.

Values are preserved as supplied by the site. Listing names were replaced with full names from the product forms. Price and description text can disagree in the source; both are preserved. Empty fields remain empty. Original description HTML is retained in JSON but is not executed in the offline catalog.
No product records were changed on the site.
